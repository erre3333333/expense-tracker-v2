🛠️ 技术栈

🎨 前端展示层

  • Vue 3 Composition API
  • Vite 5 (HMR / 热更新)
  • Tailwind CSS 3
  • ECharts 5 (图表可视化)
  • Vue Router 4 (路由守卫)

⚙️ 后端 API 层

  • FastAPI 0.110 (异步框架)
  • uvicorn (ASGI 服务器)
  • aiosqlite 0.19 (异步驱动)
  • Pydantic (数据验证)
  • CORS 中间件

💾 数据存储层

  • SQLite (本地文件数据库)
  • users 表 (用户认证)
  • transactions 表 (交易记录)
  • 自动建表 (startup hook)

🔐 安全层

  • bcrypt 密码哈希
  • python-jose (JWT)
  • Bearer Token 认证
  • 7天 Token 有效期
  • localStrorage Token 存储

D-->>A: user record A->>S: bcrypt.compare(input, hash) S-->>A: true A->>S: jwt.encode({sub:id, username}) S-->>A: access_token A-->>F: {access_token} F->>F: localStorage.setItem(token) F->>U: router.push("/") → Dashboard Note over U,D: === 业务请求 === U->>F: 操作 Dashboard F->>F: axios interceptor 附加 Bearer token F->>A: GET/POST /api/... {Authorization} A->>S: jwt.decode(token) S-->>A: {sub:userId} A->>D: CRUD transactions WHERE user_id=? D-->>A: results A-->>F: JSON response F->>U: 更新页面/图表 ✅

📋 完整操作流程
①

用户访问 http://localhost:5173

Vite 返回 index.html，加载 Vue SPA 应用

②

Vue Router 守卫检查 — 未登录 → /login

检查 localStorage.getItem('token')，无则重定向到登录页

③

用户在登录页输入用户名/密码

Login.vue 通过 Axios POST /api/auth/login

④

FastAPI 查询数据库 + bcrypt 验证

SELECT users → bcrypt.compare → 成功签发 JWT

⑤

返回 { access_token }，前端存入 localStorage

localStorage.setItem('token', data.access_token)

⑥

router.push('/') → Dashboard 加载

axios interceptor 自动添加 Authorization: Bearer xxx

⑦

并行请求: transactions, monthlyStats, trendData

三个 API 并发调用，ECharts 渲染图表，显示统计卡片

⑧

用户记账 / 编辑 / 删除

CRUD 操作通过 Axios 发送到后端，实时更新列表和图表
