Expense Tracker v2.0 — Vue 3 + FastAPI + SQLite
架构说明：四层设计（展示层 → 代理层 → 应用层 → 数据层），前端 Vue 通过 Vite 的 API 代理将 /api 请求转发到后端 FastAPI，后端通过 aiosqlite 异步连接 SQLite 数据库存储用户和交易数据。

调用说明：main.py 作为入口，通过 include_router 将三个模块注册到 FastAPI。各路由器依赖 _connect（数据库连接池）和 _connect_context（async context manager）进行数据库操作。auth.py 独立使用 passlib/bcrypt 进行密码哈希和验证，使用 python-jose 进行 JWT 编码解码。

流程说明：前端组件调用 api/index.js 封装的 Axios 方法，请求拦截器自动从 localStorage 读取 token 并添加到 Authorization 头部。Vite 开发服务器的代理配置将 /api 路径的请求转发到本地 8001 端口的 FastAPI 服务。FastAPI 通过路由分发到对应的控制器，处理完后返回 JSON 响应给前端，前端接收后更新 UI。
